# AeroMusic Player (AMP)

文化祭など、**BGM と効果音を同時に出す**ための多重再生プレイヤーです。
mp3 / wav / flac / ogg / m4a / aac / opus に対応。

---

## 起動方法は2つあります

### ① .exe 版（おすすめ）
**[Releases](https://github.com/Orahu01/AeroMusicPlayer/releases/latest) から `AeroMusicPlayer-Setup-x.x.x.exe`（インストーラ）または
`AeroMusicPlayer-x.x.x-portable.exe`（インストール不要）をダウンロード**して実行するだけです。
黒い窓は出ません。設定 の「アップデート」から**ソフト自身で新しいバージョンに更新**できます
（起動時にも自動でチェックします）。

### ② Web 版（ソースから直接動かす場合）
**`AMP.bat` をダブルクリック**します。黒いウィンドウ（サーバ）と、
アドレスバーのない専用ウィンドウ（AMP 本体）が開きます。

> ⚠️ **黒いウィンドウは閉じないでください。** 閉じると音も止まります。
> AMP 本体のウィンドウを閉じれば、黒いウィンドウも自動で終了します。

どちらの版でも、初回のみ「マイクの使用を許可しますか？」と聞かれることがあります。
これは **出力デバイスの一覧を表示するために Chrome / Electron が要求する仕様**で、
許可した瞬間にマイクは停止し、録音は一切行いません。許可しないと
出力先が「既定のデバイス」しか選べなくなります。

## 進行表（キューリスト）

左下の「**進行表**」タブで、当日の流れを上から順に並べておけます。
本番は **GO ボタン（または Enter キー）を押すだけ**で次の項目が実行されます。

| 項目の種類 | 動作 |
|---|---|
| 曲を再生 | 指定した曲を指定デッキで再生（フェードイン秒数も指定可） |
| フェードアウト | 指定デッキを指定秒数でフェードアウト |
| 停止 | 指定デッキ、または全部を停止 |
| 効果音 | 指定パッドを鳴らす |
| メモ | 音は出ません。「司会あいさつ」など進行のメモとして |

- 次に何が来るかが常に画面下に出るので、**順番を覚える必要がありません**
- ドラッグで並べ替えできます
- 項目をクリックすると「ここまで進んだ」状態にできます（進行が飛んだときの復帰用）
- 「最初から」で先頭に戻せます

> 当日オペを交代するときも、進行表があれば引き継げます。

## 曲ごとの調整（イン点・アウト点・音量の自動変化）

プレイリストの曲にマウスを乗せて「**調整**」を押します。

- **イン点** … 曲頭の無音やイントロを飛ばして、途中から再生を始める
- **アウト点** … 途中で終わらせる（間奏まで流して終了、など）
- **音量の自動変化** … 「**この時刻から ◯秒かけて 音量を◯%にする**」を並べていけます

音量の自動変化は、曲を再生しながら「**＋ 今の位置に追加**」を押すとその場所に点が入ります。
たとえば「司会が話し始める 1:20 から 3秒かけて 30% に下げて、1:50 から 2秒かけて戻す」
といった動きを仕込んでおけば、本番中にフェーダーを触る必要がありません。
設定した変化は**波形の上にカーブとして表示**されます。

---

## 音量の自動そろえ

設定 →「曲ごとの音量差を自動でそろえる」（初期状態でオン）。

ダウンロードした曲は音量がバラバラなので、読み込むときに解析して自動で近づけます。
曲が変わるたびにフェーダーを触らなくて済みます。±12dB の範囲で、音割れしない範囲に収めます。

---

## 誤操作ロック

右上の「**🔓 ロック**」を押すと、本番中の誤クリックで BGM が止まる事故を防げます。

- ロック中でも**効果音のパッドと「全停止」は使えます**（とっさの操作は殺さない）
- デッキの停止・設定変更・プレイリスト操作は無効になります

## 起動時セルフチェック

起動時に「設定した出力先が見つからない」「効果音が読み込めていない」といった問題を検出すると、
画面上部に**黄色い警告バー**を出します。当日の朝に気づけるようにするための機能です。

---

## グローバルホットキー（.exe 版のみ）

設定 →「AMP が最前面でなくても効果音のキーを効かせる」。

同じ PC でスライドや資料を出すとき、そちらをクリックした瞬間に
効果音のキーが効かなくなる事故を防げます。

- **Ctrl + Shift + パッドのキー** で鳴ります（組み合わせは設定で変更可）
- **単独のキーは奪いません**。他のソフトで文字が打てなくなるのを避けるためです
- 全停止は **組み合わせキー + BackSpace**

## 3つの出力を別々のデバイスへ出せます

AMP は音声を **3系統の独立したバス**に分けて出力します。
それぞれ **出力先デバイスを一覧から自由に選べます**（内蔵スピーカー、ヘッドホン端子、
USB オーディオ、HDMI など、Windows が認識している出力ならどれでも）。

| バス | 中身 |
|---|---|
| **BGM** | 各デッキの曲 |
| **SE** | パッドの効果音 |
| **試聴 (Cue)** | 次の曲の下見・パッドの試聴（会場には出ない） |

設定は右上の **「設定」**から。

### ミキサー（Yamaha EMX5014C など）に繋ぐ場合

**出力を2つ用意すると、BGM と効果音を卓の別チャンネルに送れます。**
そうすると **卓の物理フェーダーで BGM と効果音を別々に操作**できます。
遅延ゼロで、手で触れるので本番中は圧倒的に速いです。

```
                          ┌─────────── EMX5014C ───────────┐
  PC ヘッドホン端子 ─BGM─▶│ CH 9/10  ── fader ─┐            │
  USB オーディオ ────SE──▶│ CH 11/12 ── fader ─┼─▶ スピーカー│──▶ 会場
  マイク ────────────────▶│ CH 1     ── fader ─┘            │
                          └────────────────────────────────┘

  試聴バス ──────────────▶ ヘッドホン（卓を通さない）
```

安い USB オーディオ変換アダプタ（1000円程度）を1つ挿すだけで、この構成にできます。
設定 → BGM バスに「スピーカー（Realtek 等）」、SE バスに「USB Audio Device」を選んでください。

**出力が1つしかない場合**は、3つとも同じデバイスを選べば普通に鳴ります。
その場合の BGM と効果音のバランスは、AMP 上部の音量スライダーで取ってください。

> **マイクについて**
> マイクは PC を通さず、**卓に直接挿してください**。PC 経由にすると 40ms 前後の遅延が乗り、
> 話している人が自分の声を遅れて聞くことになります。

## BGM の使い方（左側）

### 曲を入れる
- **エクスプローラーから曲をドラッグ＆ドロップ** → プレイリストに追加
- **フォルダ** → フォルダごと一括読み込み（サブフォルダも探します）
- **＋ 追加** → ファイル選択ダイアログ

ダウンロードした mp3 をそのまま放り込んで大丈夫です。

### デッキ（数は自由に増減できます）
BGM 欄の **−／＋**、または数値を直接入力してデッキを **1〜24 枚**まで増減できます。
複数デッキがあると、1つで曲を流しながら他のデッキに次の曲を仕込めます。
出番ごとに1枚ずつ曲を入れておけば、当日は該当デッキの ▶ を押すだけになります。

> デッキが 5 枚以上のときは、プレイリストの行のボタンが
> デッキごとの「A・B・C…」から**「読込」1つ**にまとまります（空いているデッキに入ります）。
> 特定のデッキに入れたい場合は、そのデッキへ曲を**ドラッグ＆ドロップ**してください。

| 操作 | 説明 |
|---|---|
| プレイリストの曲にマウスを乗せて デッキ名ボタン（**A**, **B**…） | そのデッキに曲を読み込む |
| 曲を**ダブルクリック** | 空いているデッキに読み込んですぐ再生 |
| **試聴** | **試聴バス**（ヘッドホン）だけで下見再生。会場には出ません |
| ▶ / ❚❚ / ■ | 再生・一時停止・停止 |
| **F/I** | フェードインしながら再生 |
| **F/O** | フェードアウトしながら停止 |
| **⇄** | 今鳴っている曲たちからこのデッキへその場でクロスフェード |
| **LOOP** | その曲をループ |
| 波形バーをクリック / ドラッグ | 頭出し（シーク） |
| **VOL** | そのデッキだけの音量 |

デッキをクリックすると「選択中」になり、`Space` で再生 / 一時停止できます。

### AUTO MIX
オンにすると、曲の残りがクロスフェード秒数を切った時点で
**空いているデッキに次の曲を自動で用意して繋ぎます。** 曲間が途切れません。

## 効果音（SE）の使い方（右側）

### 音を入れる
- **パッドに直接ドラッグ＆ドロップ**（複数まとめてドロップすると連続したパッドに入ります）
- 空のパッドを**クリック**してファイル選択
- **一括読込** → フォルダ内の音を先頭から順にパッドへ流し込む

読み込んだ時点でメモリ上に展開されるので、**押した瞬間に鳴ります。**
パッドの数・列数も上部の **列／−／＋** で自由に変更できます（最大63個）。

### 鳴らす
- パッドを**クリック / タップ**
- パッド右上に表示された**キーボードのキー**を押す（`1`〜`0`, `Q`〜`P`, `A`〜`;`, `Z`〜`/`）

**同じ音を連打しても重なって鳴ります**（拍手・銃声など）。
BGM とも当然同時に鳴ります。同時発音は最大 64 音。

### パッドの設定（**右クリック**）

| 項目 | 説明 |
|---|---|
| 表示名 | パッドに表示される名前 |
| ショートカットキー | 好きなキーに割り当て直せる |
| **重ねて再生** | 連打すると音が重なる（拍手・効果音向け） |
| **鳴らし直し** | 前の音を止めて鳴らし直す（ジングル・セリフ向け） |
| **押すたび再生/停止** | トグル。ループと組み合わせて環境音に |
| **押している間だけ** | 押している間だけ鳴る |
| 音量 | そのパッドだけの音量 |
| 停止フェード | 止めるときのフェード時間（ブツッと切れるのを防ぐ） |
| ピッチ / 速度 | 0.5〜2.0倍 |
| ループ | 繰り返し再生 |
| 色 | 見分け用の帯（左端に表示） |

**SE停止** で効果音だけを一括停止できます（BGM は止まりません）。

### パッドだけを別ウィンドウに切り出す（SuperDisplay 運用）

**「別窓」**ボタンを押すと、**効果音パッドだけの操作画面**が新しいウィンドウで開きます。
これを SuperDisplay 経由でタブレット側の画面にドラッグして持っていけば、

- **タブレット側**：SEパッドをタップして操作する専用パネルに
- **ノートPC側**：BGM・ミキサー・出力設定など本体側の操作に

…と役割を分けられます。裏では `BroadcastChannel` という仕組みで
同じ Chrome プロセス内の2つの画面がリアルタイムに繋がっているので、
タブレット側で叩いた音は**ノートPC本体からそのまま出力されます**
（タブレット自体はスピーカーに繋がっている必要はありません）。
本体（AeroMusicPlayer の方）を閉じると音も止まる点は変わりません。

## WEB（YouTube・配信サービスのリンク再生）

BGM 欄の **WEB** バーの「表示」を押すと、リンク貼り付け式のプレイヤーが開きます。
リンクを貼って「読込」（または Enter）するだけです。

| サービス | 対応 |
|---|---|
| YouTube / YouTube Music | ◎ フル再生。再生/停止・音量・LOOP・F/I・F/O が使え、**BGMフェーダー・DUCK とも連動** |
| Spotify | △ 公式ウィジェット再生（ログインしていない環境では 30秒プレビュー） |
| Apple Music | △ 公式ウィジェットのプレビュー再生 |
| Amazon Music | − 埋め込み非対応のため、既定のブラウザで開きます |

- 読み込んだリンクは**履歴**に残り、クリックですぐ再生し直せます。本番前に貼って準備しておけます。
- **注意①: インターネット接続が必要です。** 会場のネット環境が不安な場合は、
  当日は音源ファイル（デッキ再生）をメインにするのをおすすめします。
- **注意②: WEB の音だけは 3 バスを通らず、Windows の「既定の出力デバイス」へ出ます。**
  Windows の既定デバイスを、卓の BGM チャンネルに繋いだ出力にしておいてください。
- 各サービスの**公式埋め込みプレイヤーをそのまま表示する方式**です。音源のダウンロードや変換は行いません。

## ミキサー（音質調整）

上部の **「ミキサー」**から、BGM / SE それぞれに次を掛けられます。

- **3バンド EQ**（ローカット・LOW・MID・HIGH）
- **コンプレッサー**（スレッショルド・レシオ・メイクアップ、下のバーでかかり具合を表示）

初期状態はすべて **OFF（素通し）** です。ここは最小限の調整に留めています。
本格的な音作りやマイクへの処理は、卓（EMX5014C）側の EQ にお任せください。

## 全体の音量

画面上部に **BGM / SE / 試聴** それぞれの
**独立した音量スライダーとレベルメーター**があります。`M` でミュート。

### DUCK（ダッキング）
オンにすると、**効果音が鳴っている間だけ BGM が自動で下がり**、
鳴り終わると元に戻ります。アナウンスやセリフを聞かせたいときに便利です。
下げ量（既定 -9dB）と戻り時間は 設定 で変更できます。

## 設定と音は自動で保存されます

操作するたびに自動保存され、次に起動したときは**そのまま同じ状態で立ち上がります**。
画面右下に「保存済 22:15」のように最後に保存した時刻が出ます。

- **パッドに登録した効果音そのもの**が保存されるので、毎回入れ直す必要はありません。
- **プレイリストの曲も復元されます。** ドラッグ＆ドロップで入れた曲は、その置き場所を
  覚えておいて次回そこから読み直します（曲データを複製しないので、何十曲あっても保存領域を圧迫しません）。
  ただし**曲ファイルを移動・削除・リネームすると読めなくなります**。その曲は赤い取り消し線で
  「見つかりません」と表示されるので、入れ直してください。
  当日まで動かさない場所（専用フォルダなど）に置いておくのが安全です。
- 音量・EQ・ダッキング・出力先・デッキ数・UIモード・進行表・曲ごとの調整・
  パッドの色やキー割当もすべて保存されます。

.exe 版の保存先は下記の**実ファイル**です（設定 →「保存先を開く」で開けます）。
アプリを更新しても消えません。

```
C:\Users\<ユーザー名>\AppData\Roaming\aeromusic-player\store\
  ├ state.json      … 設定
  └ pads\pad-0.wav … 効果音の音源そのもの
```

### 手動保存（セットの書き出し / 読み込み）

設定 →「セットを書き出す」で、**設定と効果音をまとめた `.ampset` ファイル**を作れます。

- 本番前のバックアップに（何かおかしくなっても書き戻せます）
- **USB で別の PC に持っていく**のに（音源ごと入っているので、そのまま同じ環境になります）
- 「セットを読み込む」で復元します。現在の内容は**置き換わります**（確認あり）

## 画面は「マウス用」と「タッチ用」を切り替えられます

右上のボタン（**マウス** / **タッチ**）で切り替わります。設定は記憶されます。

| モード | 用途 |
|---|---|
| **マウス** | 情報量が多く一覧しやすい。ノート PC でマウス・キーボード操作するとき |
| **タッチ** | ボタン・パッド・スライダーが指で押せる大きさになる。タブレットや SuperDisplay、タッチ対応ノート向け |

タッチ用にすると、ボタンが 46px 以上になり、
マウスを乗せないと出てこなかった操作ボタン（プレイリストの A/B/試聴 など）も常に表示されます。

### パッドはスクロールしません

**パッドは画面にぴったり収まる分だけ表示し、余りは「◀ 1/2 ▶」のページ送りで出します。**
指でなぞる操作は必ず「パッドを鳴らす」になるので、
「スクロールしようとしたら音が鳴った」「パッドの隙間しか掴めない」といったことが起きません。

- 段数は**画面の高さから自動で決まります**（「自動 3」のように表示）。
  自分で決めたい場合は「段」のスライダーを動かすと手動になり、
  もう一度「自動」ボタンを押すと自動に戻ります。
- 列数は「列」のスライダーで変えられます。

プレイリストと進行表は普通にスクロールします（こちらは指でなぞって動きます）。
タッチ用のときは、行の並べ替えはドラッグではなく **▲▼ ボタン**になります
（ドラッグだとスクロール操作と喧嘩するためです）。

> **SuperDisplay と組み合わせるなら**
> 効果音の「別窓」ボタンでパッドだけのウィンドウを開き、タブレット側の画面へドラッグしてください。
> この別窓は最初からタッチ用の大きさになっています。ノート側で BGM、タブレット側で効果音、という分担ができます。

## 本番前チェックリスト

1. AMP を起動し、**黄色い警告バーが出ていないこと**を確認
2. 設定 → 出力先が BGM / SE / 試聴 とも意図した通りか確認
3. 卓（EMX5014C）のチャンネルとフェーダーが合っているか確認
4. **BGM を1曲流しながら、効果音を数発叩いて同時に出ることを確認**
5. `Esc`（全停止）が効くことを確認 ← 事故ったときの命綱
6. マスター音量を本番の位置に決めておく
7. PC の音量ミキサーでミュートになっていないか確認
8. **進行表を頭から通しで1回リハーサル**し、GO を押すだけで流れることを確認
9. 設定 →「セットを書き出す」で**バックアップを取る**（USB に入れておくと安心）
10. 本番直前に「🔓 ロック」を押して誤操作ロックをかける
11. SuperDisplay でパッドを別窓運用する場合は、本体を閉じないことを再確認

## うまくいかないとき

**音が出ない**
→ 設定 の出力先を確認。まずは3つとも「Windows の既定デバイス」に戻すと切り分けできます。
それで鳴るなら、卓に繋いだ側のデバイス指定かケーブルの問題です。

**黄色い警告バーが出ている**
→ 「設定を開く」を押して、出力先を選び直してください。USB オーディオを挿し忘れているか、
挿す USB ポートが前回と違うと出ます。

**出力デバイスの一覧に何も出ない / 名前が空欄**
→ 設定 の「出力デバイス名を取得する」を押してマイク権限を許可してください。

**効果音の反応が少し遅い**
→ 画面下の「遅延」欄で実測値が見られます。USB オーディオを使うと内蔵より速いことが多いです。

**USB オーディオを挿し直したら音が出なくなった**
→ AMP が自動で検出して出力先を貼り直します。戻らない場合は 設定 →
「デバイス一覧を更新」→ 出力先を選び直してください。

**「別窓」がポップアップブロックされる**
→ 初回だけ Chrome がブロックすることがあります。アドレスバー右のアイコンから
このサイトのポップアップを許可してください。

**ポート 8777 が使用中と出る**
→ AMP が既に起動しています。二重起動はできません。
どうしても変えたい場合は `amp-launch.ps1` の `$PORT` を書き換えますが、
**ポートを変えると保存済みの設定・効果音は引き継がれません。**

|---|---|

## ソフトの実体について

AMP は **Web技術（HTML/CSS/JS）で作ったローカルアプリ**です。
Web版・.exe版のどちらも、裏で小さなローカルサーバ（自分のPC内・127.0.0.1）を起動して
画面を表示する構成で、外部のインターネットには接続しません（アップデートの確認を除く）。

- **署名について** → .exe には署名していません。初回起動時に Windows の SmartScreen 警告が
  出ることがありますが、「詳細情報 → 実行」で進められます。個人・身内配布の範囲では
  これで問題ありません。
- **リポジトリ** → https://github.com/Orahu01/AeroMusicPlayer （MIT License）

### 開発者向け：.exe を自分でビルドする

```bash
npm install
npm run start    # 開発時にそのまま起動して確認
npm run dist     # dist/ に インストーラ(.exe) と ポータブル版(.exe) を作る
npm run release  # ビルドして GitHub Releases に公開（要 gh auth login）
```

`package.json` の `"version"` を上げてから `npm run release` を実行すると、
新しいバージョンが GitHub Releases に公開され、既に配布済みの .exe が
起動時の自動チェックでそれを検知 → ダウンロード → ユーザーが「再起動して適用」を押した
タイミングで入れ替わります（強制的に落ちて中断することはありません）。

> Windows でビルドする場合、`winCodeSign`（署名ツール一式）に含まれる macOS 用ファイルの
> 展開でシンボリックリンク作成の権限エラーが出ることがあります。これは Windows の
> 「開発者モード」を有効にすると解消しますが、必須ではありません
> （`package.json` の `win.signAndEditExecutable: false` により、この環境では既に回避済みです）。
